Index of /mediahub-kodi/

Add https://satanlair2013-create.github.io/Mediahub-kodi/ as a file source in Kodi, then use Install from zip file. Install repository.mediahub to get automatic updates, or script.mediahub.helper and then skin.mediahub for the skin on its own. plugin.video.mediahub.xtream (MediaHub IPTV) plays an Xtream Codes IPTV service; plugin.audio.mediahub.radio (MediaHub Radio), plugin.audio.mediahub.podcasts (MediaHub Podcasts), service.mediahub.webremote (MediaHub Web Remote) and service.mediahub.sync (MediaHub Sync) go with it too.

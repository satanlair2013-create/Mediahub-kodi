Index of /mediahub-kodi/

Add https://satanlair2013-create.github.io/Mediahub-kodi/ as a file source in Kodi, then use Install from zip file. Install repository.mediahub to get automatic updates, or script.mediahub.helper and then skin.mediahub for the skin on its own. plugin.video.mediahub.xtream (MediaHub IPTV) plays an Xtream Codes IPTV service; plugin.audio.mediahub.radio (MediaHub Radio), plugin.audio.mediahub.podcasts (MediaHub Podcasts), plugin.audio.mediahub.audiobooks (MediaHub Audiobooks), plugin.video.mediahub.classics (MediaHub Classics), plugin.video.mediahub.cinema (MediaHub Cinema), weather.mediahub (MediaHub Weather), plugin.video.mediahub.scores (MediaHub Scores), plugin.video.mediahub.news (MediaHub News), plugin.image.mediahub.space (MediaHub Space), plugin.video.mediahub.recipes (MediaHub Recipes), plugin.audio.mediahub.concerts (MediaHub Concerts), plugin.audio.mediahub.relax (MediaHub Relax), service.mediahub.webremote (MediaHub Web Remote), service.mediahub.sync (MediaHub Sync) and script.mediahub.import (MediaHub Import) go with it too.
